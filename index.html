02 / ROUTE

A route you can inspect

Your context takes the short path.

Volyx Lens sends selected context directly from the app to the AI provider you configure. There is no Volyx Lens-operated intermediary server in that request path.

  • 01Provider credentials use Electron secure storage backed by macOS Keychain when available. Without secure storage, the current app uses a local plaintext credential record.
  • 02The app has no analytics or advertising SDK.
  • 03You can switch providers without changing the workflow.
  • 04Active transcript and Task Context state stays memory-only and memory-bounded for the current session, then is cleared when the session ends.

Your chosen AI provider still receives the context you send and applies its own retention and privacy terms. Review those terms before sharing sensitive material.

Before you install

A few direct answers.

Does Volyx Lens operate its own AI backend?

No. You configure your own supported provider. Requests travel from the desktop app to that provider, and the provider's own data terms apply.

Where are API keys stored?

The app uses Electron secure storage backed by macOS Keychain when available. If secure storage is unavailable, it falls back to a local plaintext credential record. The settings screen reports the storage status and lets you update or remove credentials.

Is the release notarized?

Yes. Version 0.4.0 is Apple Developer ID–signed and notarized, so it opens without right-click workarounds. SHA-256 checksums, ZIP packages, and SBOMs are published with the release.

What works offline?

AI responses require a configured provider; with a local Ollama server they run fully offline. Realtime transcription uses your configured provider (OpenAI, Azure Foundry, Deepgram, or Azure AI Speech), and optional Local Whisper covers offline batch transcription; automatic cloud fallback remains off by default.

Can I use it commercially?

Yes. The public source is licensed under the Apache License 2.0, which permits commercial use, modification, and redistribution.
